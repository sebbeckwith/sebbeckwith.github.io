# GOBBY HOMEPAGE — SECOND PASS / REFINEMENT BRIEF

That was a great first run. Now we're going to make some changes.

The first implementation established a strong visual direction and should NOT be thrown away.

The current homepage already succeeds at several important things:

- it feels significantly less like a generic AI-generated SaaS website
- the black / yellow / warm cream colour system is strong
- the large editorial typography feels distinctive
- the Rebel / Outlaw brand direction is beginning to come through
- the page has restraint
- there are no unnecessary gradients, glowing effects, glass cards or generic SaaS decoration
- the design feels relatively flat and intentional
- the large black section and large yellow manifesto section create useful visual rhythm
- the overall visual language feels much more credible and distinctive than the previous concept

Preserve those strengths.

This is NOT a request to redesign the homepage from scratch.

This is a second design and content pass intended to make the page:

- easier to understand
- more visually explanatory
- more persuasive
- more commercially effective
- stronger for SEO
- more obviously connected to the actual Gobby product
- more coherent from section to section
- less dependent on abstract copy
- still recognisably editorial and non-generic

Before editing, inspect the existing implementation and understand the current component structure and styles.

---

# 1. MAIN PROBLEM WITH THE CURRENT VERSION

The page currently looks better than it explains.

The visual language is strong, but several sections require the visitor to work too hard to understand what the copy means.

Some headlines are conceptually interesting but are too abstract without enough explanation beneath them.

Several sections are currently mostly typography.

That creates a page which is visually clean but does not demonstrate the product strongly enough.

The next version should improve:

1. INFORMATION CLARITY
2. PRODUCT VISUALISATION
3. SECTION PURPOSE
4. NARRATIVE FLOW
5. COMMERCIAL CONVERSION
6. SEO / SEMANTIC DEPTH

Do NOT solve this by simply adding more cards.

Do NOT solve this by adding generic photography everywhere.

Do NOT solve this by filling blank areas with decoration.

The primary solution should be:

> Better explanatory hierarchy + better product-led visuals + selective additional copy.

---

# 2. CORE DESIGN PRINCIPLE FOR THIS PASS

Every major section should make it immediately obvious:

> What is this section trying to explain?

A visitor should not have to infer the purpose from a tiny eyebrow label.

Eyebrow labels can remain, but they are supporting navigation cues, not the main explanation.

The hierarchy should generally be:

EYEBROW / CONTEXT

↓

CLEAR SECTION HEADLINE

↓

SHORT EXPLANATION WHERE REQUIRED

↓

VISUAL EVIDENCE / DEMONSTRATION / EXAMPLE

The page should feel like it is teaching the visitor something as they scroll.

- why Gobby is different
